## Flagship: Verdict

[Verdict Core](https://github.com/mrnicholasbcarter-code/verdict-core) is a
local-first control plane that separates model selection from authorization. It
filters candidates through deterministic capability, privacy, reliability, and
policy gates, then records why a route was admitted or excluded.

The credential-free journey demonstrates:

```text
install -> provider status -> route decision -> bounded mission
        -> forced failover -> persisted replay -> evidence
```

- [Run the verified journey](https://github.com/mrnicholasbcarter-code/verdict-core#install--provider--route--mission--failover--replay)
- [Inspect the maturity boundaries](https://github.com/mrnicholasbcarter-code/verdict-core/blob/main/docs/USER_JOURNEY.md)
- [Review public proof](https://github.com/mrnicholasbcarter-code/verdict-core/blob/main/docs/proof/EVIDENCE_INDEX.md)

The offline demonstrations use checked-in fixtures and simulated provider failure.
They do not claim live-provider availability, model quality, adoption, or production
scale.
